# 标记为未读开发计划（v1.8.0）

> 2026-09-29。来源：docs/下一期展望.md 第 4 项。v1.7.0 已建好
> `flag_sync` 的 seen=False（`-FLAGS \Seen`）通道但无 UI 入口，本版补齐。

## 需求

- 邮件列表右键菜单新增「标记为未读」：本地 `is_read=0` + 后台向服务器
  `-FLAGS (\Seen)`（与手机/网页端观感一致）。
- 已读同步关闭（sync_read_flags=False）时只改本地，行为与旧版一致。

## 实现

- `db.mark_read(id, read=False)` 已存在，直接复用。
- `MainWindow.mark_selected_unread()`：取行 → 改库 → `_sync_read_flags([mail], seen=False)`
  → 刷新列表/徽章；flag_sync 去重键含 seen 方向，与已读任务互不干扰。
- 右键菜单加入口（复用选中行）；不做工具栏按钮（低频操作）。

## 测试与发布

- seen=False 分组/切块路径已有单测覆盖；补跑全量 + 打包冒烟。
- CHANGELOG [1.8.0]、README 功能行、技术文档（中/英）更新、展望文档勾掉第 4 项。
- 提交 + tag v1.8.0。

## 边界

- 「标记为未读」不提供批量入口（避免误触大范围改服务器状态）；
  未读邮件重复标记幂等无害。
- 窄竞态（标已读→立刻标未读）已在 flag_sync 模块注释中声明接受。
