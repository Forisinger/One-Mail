# 稳定性加固 · 开发计划（v1.4.0）

> 来源：多 Agent 并行代码审查（网络并发 / UI / 数据安全三路），修复全部 P0、P1 及高性价比 P2 项。

## 一、数据安全（防丢数据）

1. **config.json / secrets.bin 原子写**：临时文件 + `os.replace()`；`load()` 失败时把损坏文件备份为 `*.corrupt` 再回默认，绝不让空配置静默覆盖原始数据。
2. **save_password 读失败不再清空密码库**：secrets 读解析失败时保留旧文件并抛错，而不是用空 dict 覆盖。
3. **迁移幂等加固**（database.py `_migrate`）：脚本前 `DROP TABLE IF EXISTS mails_new` + 显式 `BEGIN IMMEDIATE/COMMIT` 真原子；SELECT 列按实际存在的列选择，兼容更老的库。
4. **LIKE 通配符转义**：关键字中 `%`/`_` 转义 + `ESCAPE '\'`，搜「100%」不再虚配；total 与 rows 改单连接查询消除竞态。

## 二、解析与匹配

5. **parser 未闭合 `<script>/<style>` 吞正文**：`</script>` 级复位——收到任何非对应闭合标签或数据段过长时强制清零 skip 深度。
6. **guess_host 域名边界**：`domain == d or domain.endswith("." + d)`，`myqq.com` 不再连到 imap.qq.com（凭据误发）。
7. **FETCH 结果形态校验**：`isinstance(msgdata[0], tuple)` 才解析，杜绝服务器异常应答入库垃圾行。

## 三、并发与网络

8. **IDLE 等待重写**：不再对 socket 设 24 分钟大超时（`SocketIO._timeout_occurred` 污染导致超时后文件对象永久不可读、每 24 分钟必断线重连）。改为 `select.select` 分片等待（5s 一片），同时检查 `_stop` 与新的 `_wake` 事件——超时自然重发 IDLE 保活，停止/唤醒即时生效。
9. **stop() 关闭 socket**：令阻塞中的 read 立刻抛错走清理路径，杜绝线程卡死 24 分钟、双线程同拉一个邮箱。
10. **IMAP/SMTP 建连统一 timeout=15s**（含 `list_folders`）。
11. **「立即收信」真正生效**：MailClient 增加 `wake()`；IDLE 线程收到唤醒即 DONE→抓信；轮询线程等待被唤醒。fetch_now 调用之。
12. **`_poll_events` try/finally 防护**：任何事件处理器异常不再切断 after 链（防「程序活着但失聪」）。
13. **save_to_sent 复用 mUTF-7 解码**：163 的「已发送」文件夹终于能匹配并 APPEND（原来比对的永远是 `&XfJT0ZAB-` 原始字节）。
14. **SMTP 补 Date / Message-ID 头**：提升送达率与回复串接。

## 四、UI 修复

15. **编辑账户无需重输授权码**：编辑时空密码沿用已存授权码；仅新增账户强制必填。
16. **richtext emoji 错位**：`text_to_html` 与 `_toggle_font` 改为 Tcl 侧推进游标（`widget.get(idx)` + `+1c`），Python/Tcl 索引永远一致。
17. **account_dialog 获取文件夹**：worker 线程不再触碰 tk 变量（启动前取值），回填前判 `winfo_exists()`，消灭跨线程 Tcl 调用与销毁后回调。
18. **compose_window `_on_sent`**：开头判窗口存活，发送中关窗不再 TclError。
19. **右键菜单泄漏**：弹出后 `destroy()`，托盘长年运行不再累积死菜单控件。
20. **搜索防抖 300ms**：每键全表扫描改为停顿后查询。
21. **删除邮件（本地）**：邮件列表右键「删除」+ Delete 键，从本地缓存移除（服务器不动）。
