# OneMail 复制文本与启动行为 · 开发计划

> 版本：v1.1.1 规划 ｜ 日期：2026-09-29

## 一、目标

1. **软件内随处可复制文本**：
   - 阅读区：标题、元信息、正文任意片段选中复制（Text 控件原生支持，补右键菜单"复制/全选"提升可用性）
   - 邮件列表：右键菜单——复制主题 / 复制发件人姓名 / 复制发件人邮箱地址 / 复制整封正文
   - 账户面板：右键菜单——复制邮箱地址 / 复制账户名（解决"拿自己的邮箱地址"的高频需求）
2. **启动行为调整**：双击 exe 直接显示主窗口；**仅开机自启**（注册表项带 `--minimized` 参数）才静默进托盘

**不做**（记入二期）：邮件列表内联文本选择（Treeview 限制）、富文本复制（HTML 格式保留）。

## 二、技术方案

### 1. 复制工具（`ui/main_window.py` 内聚实现）
- `_copy_to_clipboard(text)`：`root.clipboard_clear/append`，状态栏提示"已复制：xxx"
- 右键菜单统一用 `tk.Menu(tearoff=0)`，`<Button-3>` 绑定

### 2. 邮件列表右键菜单
- 命中行 → 从数据库取该邮件：主题、发件人姓名、发件人地址、正文分别可复制
- 空白处右键不弹菜单

### 3. 账户面板右键菜单
- 每个账户卡片上右键 → 复制该账户邮箱地址 / 账户名
- "全部邮件"卡片不提供复制项（无对应地址）

### 4. 阅读区右键菜单
- 有选中文本 → 「复制」；始终提供「全选」
- Text 控件 disabled 状态下选择/复制原生可用，无需改状态机

### 5. 启动行为（`main.py` + `storage/config.py`）
- `start_minimized` 判定改为**仅看 `--minimized` 命令行参数**，不再读旧设置项
- `config.py` 默认值 `start_minimized: True → False`（保留键位兼容，语义改为"自启时静默"的提示性配置）
- `autostart.py` 不变——注册表里本来就是 `--minimized`，开机路径不受影响

## 四、风险与对策

- **右键与筛选点击冲突**：账户卡片左键筛选、右键菜单互不干扰（事件类型不同）
- **空内容复制**：主题/地址为空时菜单项置灰，避免复制到空值
- **旧配置残留 `start_minimized: true`**：改法不读该键，无兼容问题
